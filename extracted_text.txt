--- Slide 2 ---
Introduction
This project is a prototype of a microblogging platform inspired by Twitter (X).
It allows users to create short posts, interact with others, and view personalized content.

--- Slide 3 ---
Purpose Of The Application
Enable users to share short messages 
Allow social interaction between users 
Provide a personalized content feed 
Demonstrate relational database design using PostgreSQL
